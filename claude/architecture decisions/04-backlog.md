# Backlog — Parked Ideas

Nothing here gets built until the must-ship core (see roadmap) is done. This file exists so ideas don't get lost AND don't get built early.

## Post-launch content
- Additional zones (Ravenhold catacombs, Mountain Temple, bandit village)
- Additional creature types and elites
- Deeper alchemy tree tiers past the Elixir
- Semi-procedural zone assembly from the tile library
- Cosmetic customization for players/brewing station
- Seasonal or rotating modifier runs ("mutators")

## Systems considered and deliberately cut from v1
- Boss encounter as Elixir climax (v1 uses recipe completion instead)
- Perishable reagents (nice tension, first to cut in Phase 5)
- Full three-branch skill tree if Phase 2 runs long
- Individual player inventories (v1 uses shared team stash)

## Explicit non-goals — don't reconsider without a real reason
- PvP / other teams interfering
- Open world
- Player trading economy
- Voiced narrative or cutscenes
- Permanent skill-progress loss on failed extraction

## Ideas to revisit only after v1 ships
- Cross-platform play
- Dedicated servers (v1 should be listen-server/P2P if at all possible — dedicated servers are cost and ops overhead a solo dev doesn't need on day one)
- Mod support for custom zones
